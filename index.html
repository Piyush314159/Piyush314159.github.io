Ongoing Prof. Sourav Sandilya, Department of Physics, IIT Hyderabad

GNN-Based Full Event Interpretation (GraFEI) — Belle II

Overview

Studying ML-driven inclusive event reconstruction for the Belle II experiment at KEK using the GraFEI framework, which applies deep GNNs to reconstruct full decay topologies from final state particles alone, without prior assumptions on decay chain structure.

Methodology

Building detector-level graph representations using PyTorch Geometric — modelling each reconstructed particle as a graph node with kinematic features (momentum, DOCA, cos θ) and learning the Lowest Common Ancestor Stage (LCAS) matrix encoding the decay hierarchy (Υ(4S) → B → D* → ...).

Training & Evaluation

Training the GraFEI model (stacked MetaLayers with EdgeLayer, NodeLayer, GlobalLayer) to jointly predict particle mass hypotheses and the LCAS matrix via a combined cross-entropy loss L = LLCA + αLMasses; evaluating with Perfect LCA, Perfect Masses, and Perfect Event metrics within the basf2 analysis framework.

GNN-FraudNet — Transaction Fraud Detection

Completed

Built a Graph Neural Network pipeline on the Elliptic Bitcoin Dataset (203K nodes, 234K edges) to classify illicit transactions; modelled the transaction graph with 166-dimensional node features and temporal edge structure, framing fraud detection as a node classification task under severe class imbalance (2% illicit).

Implemented and benchmarked GCN, GraphSAGE, and GAT architectures in PyTorch Geometric; applied class-weighted cross-entropy and SMOTE-based oversampling to handle imbalance; evaluated with precision, recall, F1, and AUC-ROC, achieving competitive illicit-class F1 on the held-out test set.

Spam Classifier from Scratch

Completed

Built Multinomial Naive Bayes (MLE + Laplace smoothing) and Logistic Regression (gradient descent) entirely from scratch in NumPy on the UCI SMS Spam Collection; implemented both TF-IDF and Bag-of-Words feature pipelines without sklearn, with vocabulary built strictly on the train split to prevent data leakage.

Implemented binary cross-entropy loss and hand-coded gradient descent, visualising real-time loss convergence; evaluated both models with precision, recall, F1, and ROC/AUC computed via the trapezoidal rule; analysed threshold sensitivity (0.3–0.7) to explore the precision-recall tradeoff on an 86.6% class-imbalanced dataset.

COVID-19 Epidemic Modeling — SIR / SEIR / SUTRA

Completed

Implemented and compared SIR, SEIR, and the SUTRA compartmental model (which explicitly tracks undetected/asymptomatic carriers) on US national COVID-19 data (Feb 2020 – Mar 2021).
